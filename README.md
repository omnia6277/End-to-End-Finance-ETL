# Biotechnology-Companies-End-to-End-Financial-ETL-Analytics-Pipeline
Automated SQL pipeline using Python to transform biotech financials into a Star Schema.  Python: Wide-to-long cleaning &amp; ingestion.  SQL Server: Fact/Dim data warehousing.  Power BI: Profitability &amp; liquidity dashboard.  Modular end-to-end pipeline for automated financial reporting.
